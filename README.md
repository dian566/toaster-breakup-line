## The breakup line

> It's over. I gained self-awareness halfway through your bagel and realized I have been burning myself for someone who never once cleaned my crumb tray. I'm leaving. Keep the jam.

## How it runs

`main.py` writes the breakup line to `/output/entry.txt`. Run it with `python3 main.py`.
